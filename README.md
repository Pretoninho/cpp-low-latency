# cpp-low-latency

Parcours d'apprentissage personnel en C++ bas niveau / low-latency.

## Étapes

- [x] 1. `01-fundamentals/` — C++ moderne : RAII, sémantique de valeur et de move, templates
- [x] 2. `02-hardware/` — architecture machine : cache, false sharing, prédiction de branchement
- [x] 3. `03-cache-structures/` — structures cache-friendly : flat map vs map, mesuré avec perf
- [ ] 4. `04-lockfree/` — concurrence lock-free : atomics, memory ordering, queue SPSC (en cours)
- [ ] 5. `05-profiling/` — perf, flamegraphs, méthode top-down Intel
- [ ] 6. `06-networking/` — réseau bas niveau : io_uring, DPDK
- [ ] 7. `07-capstone/` — projet final : order book + queue sur un flux réel
